# Доска задач проекта

На компьютере задачи распределены по колонкам «Новые», «В работе», «Готово». Карточка показывает название, исполнителя, срок, приоритет, этап и число отчётов. Нажмите название, чтобы открыть подробности сбоку. На телефоне доступны переключатели колонок, а подробности занимают весь экран.

## Действия и роли

- Ученик — владелец проекта создаёт, редактирует и назначает задачи, меняет их приоритет и статус. Кнопка «+ Задача» открывает форму с названием, описанием до 3000 символов, сроком, исполнителем, приоритетом и необязательным этапом.
- Ученик — участник проекта меняет статус назначенных ему задач и добавляет отчёты по ним. Отчёты сохраняются в прежней истории.
- Учитель читает задачи и отчёты; проверка этапов, видеозащиты и персональные оценки остаются отдельными действиями.
- Задачи с отчётами не удаляются: сервер сохраняет историю работы.

Привязка задачи к одному из пяти этапов помогает планировать работу. Можно заранее подготовить задачи для будущего этапа. Завершение всех задач этапа не принимает его автоматически и не выставляет баллы — решение остаётся за учителем.

## Поиск и фильтры

Быстрые переключатели: «Все», «Мои» для ученика, «Скоро срок», «Просрочены». В «Фильтрах» доступны приоритет, срок, исполнитель, этап и сортировка. Выбранные условия показываются над доской; «Сбросить» снимает их. Проценты и показатели всего проекта продолжают учитывать все задачи, даже если доска отфильтрована.

Фильтры сохраняются в адресе. Смена статуса и отправка отчёта сохраняют выбранные условия. При фильтрах доска перечитывается с сервера после успешного сохранения; если задача перестала соответствовать фильтрам, она исчезает из текущей выборки. На телефоне выбранная колонка тоже сохраняется в адресе.

Сроки и время отчётов отображаются по Москве. «Скоро срок» включает сегодня и следующие семь дней; просроченные и завершённые задачи в эту выборку не входят.

## Клавиатура и сохранность

Название задачи открывается с клавиатуры. В открытой панели фокус остаётся внутри; Escape, «Закрыть» или нажатие на затемнённый фон закрывают панель с возвратом фокуса. Перетаскивание и обычный выбор статуса используют один серверный путь. При ошибке сохранения карточка не переносится и сообщение об успехе не появляется.

Без поддержки диалогов подробности доступны через обычные раскрывающиеся блоки; формы создания, редактирования и отчётов остаются HTML-формами. Смена статуса и приоритета, как и раньше, требует JavaScript.

Новые поля `tasks.description` и `tasks.stage_number` добавляются повторяемой штатной инициализацией приложения. Старые задачи сохраняются с пустым описанием и без этапа. SQLite backup/restore включает новые поля. Права владельца повторно проверяются под блокировкой проекта при создании и редактировании; CSRF и проверки прав для остальных действий сохранены.
