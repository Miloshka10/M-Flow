# M-Flow · Концепция 01

**Статус: первый этап полного редизайна — готов к визуальной оценке.**

Дата: 22 октября 2026. Основа: `15fc75a`. Рабочая ветка: `codex/redesign-concept`.

Это самостоятельный интерактивный прототип. Он не импортирует Flask, не читает базу, не обращается к Render/Neon, не создаёт пользователей и не отправляет сообщения. Все имена, проекты, сроки, работы и решения — демонстрационные. Изменения в формах живут только до перезагрузки страницы. Прототип не подключён к рабочему сайту.

## Открыть

Можно открыть `index.html` обычным браузером, без установки зависимостей. Или из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m http.server 5092 --bind 127.0.0.1 --directory design/concept-v2
```

- Главная ученика: <http://localhost:5092/#student>
- Кабинет учителя: <http://localhost:5092/#teacher>
- Пространство проекта: <http://localhost:5092/#project/overview>
- Проект глазами учителя: <http://localhost:5092/#project/overview/teacher>

Переключатель трёх экранов сверху — инструмент просмотра концепции. Он не войдёт в рабочий интерфейс. Размер окна автоматически переключает компьютерную и мобильную компоновки. Внизу главной ученика доступны примеры первого входа, доработки и ожидания проверки.

## Три ключевых экрана

1. **Главная ученика.** Текущий проект и одно следующее действие; рядом ближайшие задачи. Другие проекты и учебная группа ниже. Первый вход объясняет путь и предлагает код группы / создание проекта.
2. **Кабинет учителя.** Очередь работ на первом плане, отдельно сигналы о сроках задач. Проекты можно искать и фильтровать. Группы доступны рядом с очередью.
3. **Пространство проекта.** Общие разделы: обзор, пять этапов, задачи, команда, защита и результат. В обзоре — следующий шаг, комментарий руководителя, принятые этапы, сопровождение и история решений.

В прототипе раскрываются задачи, доработка этапа, история, решение учителя, группы, профиль и настройки. Образцы остальных форм обозначены как образцы, а не завершённая интеграция.

## Общий визуальный язык

| Элемент | Решение |
| --- | --- |
| Основной фон | Молочный `#F6F5F1` |
| Поверхности | Белый `#FFFFFF`, тёплый `#FFFEFA` |
| Основной текст | Графит `#25272D` |
| Вторичный текст | `#6D7079` |
| Главный акцент | Кобальт `#274DE5` |
| Спокойные дополнительные поверхности | Шалфейный `#E9EEE4`, светлый кобальт `#ECEFFF` |
| Обратная связь | Текстовые статусы; зелёный / янтарный помогают различать их |
| Типографика | Segoe UI Variable / Segoe UI / Arial, без внешних запросов; крупные заголовки 32–42 px, компактные подписи, выразительные числа |
| Геометрия | Карточки 18 px, элементы управления 8 px, тонкие разделители |
| Логотип | Текстовый M-Flow с кобальтовой точкой, без отдельного квадрата или эмблемы |
| Иллюстрация | Лёгкая векторная схема проекта, встроенная в прототип; не загружается извне |

Настольное меню постоянно слева. На телефоне оно открывается поверх страницы, удерживает фокус и закрывается по Escape / нажатию снаружи. Аккаунт остаётся текстовой кнопкой. Детали открываются в правой панели на компьютере и на всю ширину телефона. Этапы перестраиваются из горизонтальной последовательности в вертикальную. Доска на телефоне показывает выбранную колонку.
