# Объединённая работа по пяти этапам

27 октября 2026. Реализация утверждённого [макета](../workspace-prototype/README.md). Ветка `codex/project-workspace` создана от актуального `origin/main` (`ac93f45`), незавершённых изменений на старте не было.

## Изменения

Один пункт «Работа над проектом»: маршрут пяти этапов, следующий шаг, список дел, результат и замечания/проверка рядом. Сохранены текущие темы, типографика и значки. На телефоне — вертикальная компоновка. Формы задач и черновика открываются в панелях с удержанием фокуса; учитель проверяет отправленный результат в его контексте.

Прежние адреса этапов и задач работают. Задачи без этапа сохранены; выполненные сворачиваются. Поиск, все фильтры, сортировка, ближайшие сроки, назначение, приоритет, отчёты, управление командой, сопровождение, защита, история и личные оценки остаются доступны. Новые задачи получают просматриваемый этап. Сохранение статуса/приоритета перечитывает серверную выборку после успеха.

Серверные правила сдачи/проверки, права, CSRF, optimistic locking, схема БД и внешние настройки не менялись. Принятие этапа не следует из выполнения задач, принятие защиты не публикует оценку автоматически.

## Проверки

- Полный локальный Python-прогон: **561 тест, OK, 3 пропуска**, временные SQLite-базы и отдельная локальная PostgreSQL-база `mflow_test`. Временные схемы создают и удаляют сами тесты. Первая попытка в Windows sandbox не позволила создавать жёсткие ссылки для backup-тестов; повторный полный запуск с доступом к локальной тестовой среде прошёл.
- **8 JavaScript-наборов** прошли, включая новую проверку сохранения этапа после переноса формы в диалог. Этот набор включён в CI.
- Добавлены 7 интеграционных регрессионных сценариев (SQLite и PostgreSQL): старые входы, уникальные DOM-адреса, CSRF/версии/проверки ролей, восстановление ошибочной формы, безопасный возврат в тот же проект, выбор этапа и чужие проекты.
- Браузер: **56 сочетаний** двух тем, ширин 320/390/768/1440 px, обеих ролей, проектов с доработкой/работой, проверкой, завершением и отсутствием руководителя. Горизонтального переполнения по измерениям DOM не обнаружено. [Записи](browser-checks.json).
- Отдельно в браузере: выбор этапа и «Мои» с сохранением выбора; выполненная задача по прямой ссылке; создание и назначение задачи; завершение без принятия этапа; отчёт; черновик, повторная сдача, обязательное замечание, возврат и принятие с открытием следующего этапа; сохранность старых версий и решений. Проверены Tab/Shift+Tab, Escape, возврат фокуса и форма на телефоне.
- Участник не получил создание/редактирование задач команды, видит статус только собственных назначений и свою форму отчёта. Чужие проект и оценка в браузере вернули страницу 403. Серверные регрессии покрывают прямые запросы, в том числе без CSRF.

Все пользователи, проекты, отчёты, сдачи и решения браузерной проверки синтетические, в `tests/preview_interface.py`. Рабочие аккаунты/данные для проверки не использовались.

## Ограничения и выпуск

Авторизованные сценарии проверены локально. На production допустимы только публичные страницы, загрузка ресурсов и `/health`; без разрешённого тестового доступа рабочие проекты не открываются и не создаются. Физические телефоны, Safari/Firefox и экранный диктор не проверялись. Обычные HTML-блоки/формы сохраняют работу без улучшений JavaScript; отдельное отключение JavaScript в браузере не проверялось.

Публикация — PR с CI Python 3.12/3.14 и PostgreSQL, затем один squash-коммит в main и существующий Auto-Deploy. Ручной production-деплой и миграции не выполняются. Итоговые идентификаторы CI/деплоя — в отчёте выпуска после завершения.

Скриншоты в `screenshots/`: реальные страницы приложения на изолированной базе, без управления демонстрацией из макета.
