# Рисованная среда M-Flow

Одобренное направление: свободные линии синей тушью, два оттенка синего, много воздуха и школьная проектная работа. Сцены созданы встроенным `image_gen` с пользовательским референсом; чужая иллюстрация не включена в приложение. Полный набор промптов — в [prompts.md](prompts.md).

## Размещение

- `workshop`: вход ученика, восстановление доступа и рабочие страницы ученика.
- `review`: вход и рабочие страницы учителя.
- `together`: учебные группы и команды обеих ролей.
- `mobile`: отдельная компактная композиция для ширины до 900 px.

Рисунок занимает отдельную область, скрыт от скринридеров и не принимает нажатия. На рабочих экранах от 1440 px для него зарезервирована полоса справа; на входе и восстановлении — от 1100 px. Содержимое учитывает ширину этой полосы. При меньшей ширине рисунок следует после всего содержимого обычным блоком, поэтому раскрытые пояснения, масштаб и высота окна не приводят к наложениям. Печать и режим высокой контрастности отключают графику и возвращают свободную ширину тексту.

Для полосы подготовлены самостоятельные портретные сцены 1:3. Промпты — в [portrait-prompts.md](portrait-prompts.md). На входе все дополнительные пояснения собраны внутри раскрывающегося блока в непрозрачной карточке формы.

## Файлы и загрузка

Рабочие файлы находятся в `static/scenery/`: прежние 14 горизонтальных WebP сохранены для совместимости и нижней композиции. Добавлены шесть портретных файлов 480×1440 px для трёх сюжетов в обеих темах. Всего 20 WebP с альфа-каналом, около 2.45 MB на комплект. Одна страница выбирает только нужный файл: примерно 31–35 KB для мобильной композиции, 64–101 KB для горизонтальной нижней области, 103–165 KB для вертикальной полосы. На ширине до 900 px компоновка и мобильный файл переключаются одновременно.

Тему выбирает CSS через существующий `html[data-theme]`, поэтому ручная настройка M-Flow имеет приоритет над темой системы. Дополнительный JavaScript, зависимости приложения, анимация и внешние запросы не нужны.

Оптимизация: уменьшение без увеличения исходников и перекодирование через Sharp; WebP quality 76, alphaQuality 65, effort 6. Оригиналы генерации сохранены только в локальном игнорируемом каталоге `.tools/art-direction/originals/`.

Изменения относятся к представлению. Обработчики, данные, пять этапов, история, оценки, права и CSRF не изменены.
