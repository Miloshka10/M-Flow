# Единые значки M-Flow

26 октября 2026. Продолжение одобренного варианта бокового меню.

## Что обновлено

Единый набор из 34 контурных SVG: сетка 24×24, линия 1,75, скруглённые окончания. В боковом меню размер 22 px, в остальных местах 14–20 px по назначению. Значки наследуют цвет текста и работают в светлой и тёмной темах.

- Навигация обеих ролей, мобильная панель, уведомления и меню аккаунта.
- Разделы проекта, история, защита и оценивание; принятые этапы получили такую же галочку, как кнопки решений.
- Поиск, фильтры, создание, редактирование, сохранение, отправка, принятие, возврат, удаление и выход.
- Группы, приглашения, согласование руководителя, отчёты, профиль и настройки.
- Текстовые стрелки в шаблонах заменены SVG. Внутренний переход и внешняя ссылка на видео/презентацию различаются. Пользовательские тексты не преобразуются.

Подписи действий сохранены. SVG декоративные (`aria-hidden`, `focusable=false`), CSS-значки также не добавляют текст для скринридера. Аккаунт остался без стрелки раскрытия. На телефоне значки вкладок проекта расположены над подписями. Выход остаётся POST-формой с CSRF.

Серверные действия, URL, поля форм, права, критерии, история и схема данных не менялись. Новых зависимостей или внешних запросов за иконками нет. Архивная копия приложения в `M-Flow-main/` не используется и не редактировалась.

## Устройство набора

Источник — `interface._ICONS`, серверный вывод — `interface.icon()`. Декоративные значки кнопок используют тот же набор через CSS-маски, чтобы не исчезать после обновления текста средствами JavaScript.

После изменения рисунков значков:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/build_icons.py
```

Команда обновляет `static/icon-symbols.css`; этот файл включён в Git и не требует сборки на сервере. Он содержит самостоятельные SVG с пространством имён XML и фиксированным размером. Для отсутствовавшего пространства имён, из-за которого CSS-маски сначала не рисовались, добавлена регрессионная проверка в `tests/test_interface.py`.

## Проверка интерфейса

[232 замера браузера](screenshots/browser-checks.jsonl): обе роли, обе темы, 320/390/768/1440 px. В проверенных состояниях нет горизонтального переполнения или отсутствующей CSS-маски; SVG исключены из отдельного клавиатурного фокуса. Дополнительные замеры после последних правок охватывают проект и результаты ученика.

Вручную проверены панель создания задачи, её закрытие по Escape, мобильные вкладки проекта, кнопки принятия и возврата учителя, оформление оценивания, меню аккаунта и его закрытие. Текст и значок выхода выровнены по профилю и настройкам. Это проверка интерфейса на временной локальной базе, не утверждение о выполнении всех действий на каждой странице.

Пройдены семь существующих JavaScript-наборов, проверки общей оболочки обеих ролей, заголовков и самостоятельности SVG-изображений. Локально выполнены 315 тестов SQLite (2 условных пропуска) и 231 тест PostgreSQL (1 пропуск); новая SVG-проверка прошла отдельно. Последние изменения шаблонов дополнительно проверены пятью прицельными тестами. Первое подключение к PostgreSQL завершилось таймаутом из-за неверного локального порта; после уточнения порта весь PostgreSQL-набор прошёл. CI перед выпуском проверяет полный итоговый набор. Результат публикации фиксируется отдельно после CI.
