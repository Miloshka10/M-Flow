# Проверки выпуска структуры интерфейса

4 ноября 2026. Основа: `17ccc6b`. Ветка: `codex/interface-navigation-release`.

## Исправления

- UI-01: возврат к списку проектов по роли, с контекстом выбранного проекта ученика.
- UI-02: действия с результатом открывают панель результата этапа из главной, обзора,
  результатов, группы и старых уведомлений. Обычный выбор этапа не меняется.
  Сохранение, сдача и решение возвращают к результату, включая телефон.
- UI-03: карточка учителя различает работу и возврат на доработку.
- UI-04/UI-05: четыре основных раздела каждой роли; заголовок, вкладка браузера,
  указатель положения и подсветка соответствуют проектам/результатам.
- UI-06/UI-07: единый вход «Защита и результат» ведёт к подготовке; история вне
  четырёх вкладок проекта. На телефоне вкладки занимают два ряда.
- UI-08: раздел руководителя сохраняет контекст доступного проекта и предлагает
  его владельцу в выборе; полномочия и согласования прежние.
- UI-09: один вход по коду группы, без пустых повторов и фильтров.
- UI-10: каталог участников и полученные приглашения видны из списка проектов;
  пустое состояние приглашений не скрывает точку входа.
- Дополнительно исправлены найденные при проверке дефекты этих изменений:
  видимость главной карточки над списком, светлый текст пустого старта,
  отступ предупреждения о сроке, прокрутка прямых ссылок и фокус заголовка.

## Локальные проверки

- Python: 722 теста, успешно; 298 PostgreSQL-проверок пропущены локально.
  PostgreSQL обязателен в CI, локальный результат его не заменяет.
- JavaScript: все 12 существующих наборов прошли. Добавлены проверки заголовков,
  положения, фокуса, истории браузера и пустых фильтров.
- Добавлены пять регрессионных сценариев Python для навигации, переходов к результату,
  контекста руководителя/отказа постороннему, пустого старта/приглашений и возврата
  после реального POST сдачи. Сценарии включены в обе ветки тестирования БД.
- Браузер: 240 сочетаний страниц, ролей, тем и ширин 320/390/900/1440 px;
  горизонтального переполнения не обнаружено. Проверены пустой старт, несколько
  проектов, черновик, ожидание, доработка, предыдущий принятый результат, завершение,
  группы, команда, руководитель, история, защита и личная оценка.
- Пройден цикл: повторная сдача → возврат учителем с замечанием → новая сдача →
  принятие → следующий этап. Проверены отправка черновика и ожидание проверки.
- Ученик без собственных проектов получил и принял приглашение: команда открылась,
  проект появился в «Моих проектах». Проверено на одноразовой синтетической базе.
- Меню обеих ролей открывается с клавиатуры; Escape закрывает меню и возвращает фокус.
  Меню аккаунта закрывается снаружи, сообщает aria-expanded; выход остаётся POST с CSRF.

## Границы результата

Рабочая база, настройки Render/Neon и миграции production не затрагивались.
Авторизованные сценарии проверялись на синтетических данных, не на рабочем сайте.
Физический телефон и программа экранного доступа не использовались;
проверка в браузере не является сертификацией WCAG или отсутствия всех ошибок.
Новые функции и новый визуальный стиль не добавлялись.

## Выпуск

После коммита: PR → успешный CI с PostgreSQL → слияние → существующий Auto-Deploy.
Точные ссылки на PR, CI и результат публичной проверки приводятся в сообщении выпуска.
Ручной production-деплой и проверочные аккаунты на production не нужны.
