## Основное решение

Ученик: **Главная → Мои проекты → Учебные группы → Мои результаты**.

Учитель: **Кабинет → Проверка работ → Проекты учеников → Учебные группы**.

Проект: **Обзор → Работа над проектом → Команда → Защита и результат**.
История остаётся доступна на каждой странице проекта отдельной ссылкой рядом
с названием. Поиск участников и приглашения — в разделе проектов и внутри команды;
оценивание учителя — в карточке проекта и в завершении проекта.

Структура согласована и внедрена. Старые адреса и прямые ссылки сохранены;
перенос пункта не удаляет его функцию.
