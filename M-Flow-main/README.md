# M-Flow

M-Flow — веб-приложение для учителя и учеников: проекты, Kanban-доска, дедлайны, приоритеты и персональное назначение задач.

## Возможности

- вход для учителя и ученика;
- создание проектов и добавление участников;
- назначение задач ученикам;
- статусы «Новые», «В работе», «Готово»;
- прогресс по каждому ученику и просроченные задачи;
- адаптивный интерфейс для компьютера и телефона.

## Локальный запуск

```powershell
python -m pip install -r requirements.txt
python -m flask --app app run
```

Откройте `http://127.0.0.1:5000`.

Для демонстрации после первого запуска доступны учётные записи:

- учитель: `uchitel` / `1234`;
- ученик: `milosh` / `1234`.

## Настройки для публикации

Перед публикацией задайте случайный секретный ключ в переменной окружения `M_FLOW_SECRET_KEY`. При необходимости путь к SQLite-базе можно вынести в `M_FLOW_DATABASE`.

```powershell
$env:M_FLOW_SECRET_KEY = "замените-на-длинный-случайный-ключ"
```
