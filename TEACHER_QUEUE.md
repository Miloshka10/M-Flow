# Очередь работ учителя

Центр проверки находится по адресу `/teacher/review`. В кабинете
`/teacher#review-queue` остаются счётчик ожидающих работ и ссылка в центр.
Дедлайны задач учеников показаны отдельно. Просрочка задачи не означает,
что учитель просрочил проверку.

Решения требуют текущий этап в состоянии `review` и видеозащита в состоянии
`submitted`. При повторной сдаче учитель видит текущую версию и замечание к
предыдущей. Отчёты находятся в отдельном фильтре и показывают последний по ID
отчёт каждой задачи. Чтение уведомления или отчёта не меняет состояние работы.

Дата новой сдачи берётся из истории. Для ранее сохранённой работы используется
дата её изменения, если она доступна. Пустые и некорректные даты идут в конце
при любом порядке сортировки. Время показано по Москве.

| Параметр центра | Смысл |
| --- | --- |
| `q` | Поиск проекта, автора, участника или работы, до 100 символов |
| `project` | Один доступный проект |
| `kind` | `all`, `stage`, `defense`, `report` |
| `sort` | `oldest` или `newest` |
| `page` | Страница очереди, до 20 пунктов |
| `work` | Прямая ссылка на выбранную работу |

Ссылки старой очереди с параметрами `kind` или `sort` перенаправляются
в центр. Параметр `focus` используется для фильтра проектов в кабинете.

Кабинет показывает до 12 карточек проектов на страницу и до шести ближайших
задач, требующих внимания. Счётчики кабинета учитывают все доступные проекты.
Запросы сводки агрегируют задачи в базе. Центр загружает метаданные работ
без сводки задач. Текст отчёта читается только при открытии этого отчёта.
Фильтры и сортировка центра применяются к метаданным до разбиения на страницы.

Права проверяются при открытии работы и при сохранении решения. Просмотр
очереди не меняет уведомления или результаты.
