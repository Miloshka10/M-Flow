# Локальный помощник M‑Flow

При включённом `M_FLOW_OLLAMA_MODEL` ученик открывает редактор текущего этапа, вводит описание результата и нажимает «Получить совет по доработке». Ollama получает описание, цель и критерии доступного задания, название этапа и замечание учителя. На экране видны проверка критериев, короткие цитаты и конкретные шаги. Совет не отправляет черновик на проверку. Официальную оценку публикует учитель.

При сдаче этапа ученик может выбрать папку с исходниками или приложить ZIP с её содержимым. Файлы связываются с конкретной отправкой. Черновик можно сохранить отдельно. Сравниваются до 60 текстовых файлов в UTF‑8, до 64 КБ на файл и до 384 КБ суммарно. Приложение хранит текст снимка в базе.

Учитель открывает «Анализ сдачи» в центре проверки. M‑Flow показывает изменение текста и ссылки между двумя последними сдачами этого этапа или видеозащиты. Если к обеим сдачам этапа приложены исходники, сразу видно, какие файлы добавлены, удалены или изменены, сколько строк поменялось и какие объявления функций Python появились или исчезли. Модель объясняет возможные функциональные изменения по фрагментам, а проверить их работу можно запуском самого проекта.

Оба сценария используют `POST /api/chat` по адресу `127.0.0.1`. Настройки `M_FLOW_OLLAMA_MODEL` и `M_FLOW_OLLAMA_PORT` задаются в окружении процесса приложения. Запустите Ollama с `OLLAMA_NO_CLOUD=1` и скачанной моделью. Для рабочего сайта по умолчанию помощник выключен. При старте M‑Flow создаёт таблицу для исходников. Ранее сохранённые сдачи доступны как сравнение описаний.

Чтобы повторить проверки локально, выполните `python -m unittest discover -s tests -p test_local_assistant.py` и `python -m unittest discover -s tests -p test_teacher_cabinet.py -k local_assistant`. Эти проверки используют имитацию ответа модели. Сквозной показ на этом ноутбуке запускается через `.tools/local-assistant-demo/Start-MFlow-AI.cmd`.
